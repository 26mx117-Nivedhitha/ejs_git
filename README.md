
# EJS Application

## Project Description
This project is developed using Node.js, Express.js and EJS.

## Technologies Used
- Node.js
- Express.js
- EJS
- HTML

## Installation

Install the required packages:

npm install

## Run the Application

node app.js

## URL

http://localhost:3000

## Features
- Home page
- About page
- Courses page
- Student details
- Student result using EJS conditions
